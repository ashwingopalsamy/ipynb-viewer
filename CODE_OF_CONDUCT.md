# Code of conduct

Keep every discussion about the viewer, the notebooks and the code.

- Be courteous and direct. Disagree with ideas, not with people.
- No harassment, insults or personal attacks, in any channel of this project.

The maintainer may edit or remove comments, issues and pull requests that break these rules, and may block anyone who keeps doing it. Report conduct problems privately through a [GitHub advisory](https://github.com/ashwingopalsamy/ipynb-viewer/security/advisories/new) or at [ashwingopalsamy.in](https://ashwingopalsamy.in).
