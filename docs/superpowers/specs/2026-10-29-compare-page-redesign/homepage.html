Markdown

Edit the text. Keep the outputs.

Double-click a Markdown cell and write in the page you are reading. Saving changes only the text you edited, so code, figures and tables stay exactly as they were. A .md file from your disk opens the same way.

  • Edit any Markdown cell: double-click it, or press e
  • Code and outputs are never changed, and nothing runs
  • Opens .md and .markdown files too, by picking or dropping
  • Save writes the same file in Chromium; others download a copy

Privacy

Where your file goes.

Opening a notebook usually means a server, and sharing one means putting it on somebody else’s. This page reads the file where it is, and once it is open the page shuts its own connections. The browser enforces that, so even a bug could not send your file out.

Grey stops are someone else’s computer. Outlined stops can run code.

The offline copy

After the first visit the app keeps its own files on your device: 31 files and about 2.1 MB, downloaded once. Open a notebook with the wifi off and it still opens.

Check it yourself

  1. Open the browser’s developer tools, Network tab.
  2. Switch the wifi off and reload.
  3. Drop a notebook. Nothing is requested.
Safety

A notebook is untrusted input.

Markdown and HTML outputs are cleaned before they are shown, and styles that could fetch anything are dropped. An output that carries a script waits behind a button and runs in a sandboxed frame that cannot reach your page, or the network unless you turn that on.

Speed

Small on purpose, quick on big files.

The first screen weighs 28 KB gzipped; math and highlighting load only when a notebook asks. The file is read in chunks, and each cell is handed over the moment it is whole.

Everything else

Made for reading, and for small edits.

Every action has a single key. Keys stand down in text fields and when you hold a modifier.

  • Search/Across text, code and outputs, with each match marked in its cell.
  • FiguresEvery plot on one shelf, and each one saves as an image.
  • Run orderSee the cells in the order they ran, and the ones that ran out of turn.
  • Live refreshSave the notebook and the view follows, in Chromium browsers.
  • Share by linkThe link carries the notebook after the #, so no server sees it.
  • ScreenshotssA clean image of a cell, ready for a post or a doc.
  • Copy as MarkdownmThe notebook as text, for a doc or for a model, secrets hidden.
  • Edit in placeeDouble-click any text and write. Code and outputs are never touched.
  • Trace a namefEvery cell that defines or uses it, one key apart.
